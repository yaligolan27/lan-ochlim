# לאן אוכלים · מפת הגודיס

מפה של המסעדות שמכבדות גודיס (לפי הרשימה מ-18.10.26), עם ניווט בגוגל מפות ובוויז, ושכבה חברתית: פרופיל, קבוצות פרטיות, מפגשי צהריים, „יוצאים לאכול”, רולטת צהריים ודירוגים של החבר׳ה.

- אתר סטטי (HTML/CSS/JS בלי בנייה), מתארח ב-GitHub Pages.
- מפה: Leaflet + אריחי OpenFreeMap. עם מפתח Google Maps ב-`config.js` עוברים למפת גוגל ולתמונות, דירוג ותפריט מגוגל.
- שרת: Supabase (פרויקט space-wall), טבלאות ופונקציות עם הקידומת `gd_`. הגישה רק דרך פונקציות RPC, עם קוד הצטרפות וקוד אישי.
- נתוני המסעדות: `restaurants.json`.
